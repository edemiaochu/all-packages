## Description

The **@szewtwin/core-react** package contains general purpose React components, such as Dialog, MessageBox, SearchBox, RadialMenu.

## Usage

To get started with the `@szewtwin/core-react` package, simply import the necessary components and utilities:

```tsx
import { ContextMenu, ContextMenuItem } from "@szewtwin/core-react";

export function App() {
  return (
    <ContextMenu>
      <ContextMenuItem>Item 1</ContextMenuItem>
    </ContextMenu>
  );
}
```

For more details, check out the [@szewtwin/core-react documentation](https://www.szewtwinjs.org/reference/core-react/).
