## Description

The **@szewtwin/components-react** package contains React components that are data-oriented, such as PropertyGrid and Tree.

## Usage

To get started with the `@szewtwin/components-react` package, simply import the necessary components and utilities:

```tsx
import { Panel, Title } from "@szewtwin/components-react";

function ListPanel() {
  return (
    <Panel>
      <Title>Panel title</Title>
    </Panel>
  );
}
```

For more details, check out the [@szewtwin/components-react documentation](https://www.szewtwinjs.org/reference/components-react/).
