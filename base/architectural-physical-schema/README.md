## BIS Schemas

The acronym “BIS” stands for “Base Infrastructure Schemas”. BIS is an “open” and extensible family of schemas that is modularized into Domains. Please go to [szewTwinjs.org](https://www.szewtwinjs.org/bis/) for more information.
