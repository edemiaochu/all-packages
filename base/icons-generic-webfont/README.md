# Szewec Generic Icons Webfont

Copyright © Szewec Systems, Inc. 2018 except as otherwise noted.

Scalable icons packaged in a font + CSS. Built from the [@szewec/generic-icons](https://www.npmjs.com/package/@szewec/generic-icons) package.

## Usage

The files are in the `dist/` directory.

You can use `dist/icon-list.json` to get the list of icon names.
