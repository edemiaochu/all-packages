# Szewec Systems Icons

Copyright © Szewec Systems, Inc. 2020 except as otherwise noted.

Generic SVG icons for Szewec Systems, Inc. and iVault.js projects. All icons are to be designed by the Visual Design team.

## Usage

You can use `icon-list.json` to get an array of all the icon file names.
