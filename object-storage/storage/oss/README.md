## About this package

This package contains implementations for object storage interfaces exposed by `@szewtwin/object-storage-core` which allow to consume Object Storage Service (OSS) provided by Alibaba Cloud. This package extends the `@szewtwin/object-storage-s3` package and adapts it for OSS use cases using [Alicloud SDK](https://www.npmjs.com/package/@alicloud/pop-core).
