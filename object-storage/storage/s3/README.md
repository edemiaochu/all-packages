## About this package

This package contains base implementations for object storage interfaces exposed by `@szewtwin/object-storage-core` that allow to consume S3-compatible storage providers. Communication with S3 is implemented using using [AWS SDK](https://www.npmjs.com/package/@aws-sdk/client-s3).
