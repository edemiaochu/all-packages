## About this package

This package contains implementations for object storage interfaces exposed by `@szewtwin/object-storage-core` which allow to consume [MinIO](https://min.io/) service. This package extends the `@szewtwin/object-storage-s3` package and adapts it for MinIO use cases using [MinIO JavaScript Library](https://www.npmjs.com/package/minio).
