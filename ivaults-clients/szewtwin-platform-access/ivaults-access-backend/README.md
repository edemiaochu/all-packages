## About this package

This package contains an implementation of [`BackendHubAccess`](https://github.com/szewTwin/szewtwinjs-core/blob/master/core/backend/src/BackendHubAccess.ts) interface. The implementation uses the [`@szewtwin/ivaults-client-authoring`](../../clients/ivaults-client-authoring/README.md) package and adapts it to the defined interface thus enabling the applications built using [szewTwin.js](http://www.szewtwinjs.org) library to use [iVaultHub service](https://developer.szewec.com/apis/ivaults-v2/#ivaulthubservice) as a repository for iVaults.
