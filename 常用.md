##   安装 nrm                                                                                                                                                                                                                                                                                                                                                                      

  npm install -g nrm                                                                                                                                                                                                                                                                                                                                                              常用命令

  ###### 列出所有可用源
  nrm ls

  ###### 切换到官方 npm（发布前必须执行）
  nrm use npm

  ###### 切换到淘宝镜像（国内开发）
  nrm use taobao

  ###### 测试各源速度
nrm test

######   发布流程可以简化为：

1. 切到官方源

  nrm use npm

2. 确认当前源

  npm config get registry   # 应输出 https://registry.npmjs.org/

3. 发布（用环境变量传 token）

  rush publish --apply --publish --npm-auth-token $NPM_AUTH_TOKEN

4. 发布完后切回国内源

  nrm use taobao

  添加自定义源（如公司私有 registry）

  nrm add company https://npm.your-company.com/
  nrm use company

---
  注意事项
  │         场景          │                                       建议                                        │
  │ 发布到 npm.org        │ nrm use npm 后，确保 token 有效                                                   │
  │ Rush monorepo         │ nrm 只改 registry，rush publish 的 --npm-auth-token 仍需单独提供                  │
  │ Scoped 包（@iproject/*） │ 若 scope 指向不同 registry，需额外配置 npm config set @iproject:registry https://... │

  nrm 本质上就是帮你自动改 ~/.npmrc 中的 registry 字段，省去了手动编辑的麻烦。



## NPM config

方式一：命令行配置（推荐临时使用）                                                                                                                                                                                                                                                                                                                                            

设置全局 registry                                                                                                                                                                                                                                                                                                                                                           

  npm config set registry https://registry.npmjs.org/                                                                                                                                                                                                                                                                                                                         

设置特定 scope 的 registry（如 @iproject）

  npm config set @iproject:registry https://registry.npmjs.org/

设置认证 token（用于发布）

  npm config set //registry.npmjs.org/:_authToken=your-npm-token

验证

  npm config list

---
  方式二：直接编辑 ~/.npmrc

打开用户级配置

  notepad ~/.npmrc        # Windows
  code ~/.npmrc           # VS Code
  nano ~/.npmrc           # Linux/macOS

  写入以下内容：

  registry=https://registry.npmjs.org/
  @iproject:registry=https://registry.npmjs.org/

认证 token（替换为你的 Automation Token）

  //registry.npmjs.org/:_authToken=your-npm-automation-token

  always-auth=true

  ▎ ⚠️  注意：你的当前 ~/.npmrc 使用的是 registry.npmmirror.com（淘宝镜像），发布前必须先切回 registry.npmjs.org，否则无法发布。

---
  方式三：环境变量（最安全，推荐 CI / 自动化）

  不将 token 写入任何文件，通过环境变量传递：

Windows PowerShell

  $env:NPM_AUTH_TOKEN="your-npm-automation-token"

Windows CMD

  set NPM_AUTH_TOKEN=your-npm-automation-token

Linux / macOS / Git Bash

  export NPM_AUTH_TOKEN=your-npm-automation-token

  然后执行 rush publish：

  rush publish --apply --publish --npm-auth-token $NPM_AUTH_TOKEN

  Rush 会自动使用该 token，无需在 .npmrc 中硬编码。

---
  常见场景

  删了重新发：

  # 1. 删除旧版本
  npm unpublish @tom-and-lily/build-tools@1.0.0

  # 2. 修改 package.json 版本号（不能和已删除的重复）
  # 改为 1.0.1 或 1.0.0-1

  # 3. 重新发布
  npm publish --access public

  添加其他人为维护者（代替删除）：

  npm owner add 用户名 @tom-and-lily/build-tools
