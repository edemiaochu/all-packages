## 问题与解决
- 已确认 token 保存刷新后从候选消失 → × 无法重新选择：根因是候选清单用含 token 规则的映射计算；改为不含 token 规则的映射 + 前端 `confirmedState` 隐藏
- 标题 `undefined`：多词模式 session 没有 `searchWord` 字段，而 `<title>` 直接插值；改成和 `<h1>` 一致的模式判断
- 「恢复初始值」名字有误导：它只重置界面（基准词回到原始搜索词、清未保存的 override），已保存 override 会因 render 回退逻辑恢复；文档按实际行为写清楚
