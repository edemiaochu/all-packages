## 问题与解决

- 点击「忽略」后条目不消失：前端 `render()` 未按 `skipState` 过滤
- 保存后撤销忽略直接消失：服务端把已忽略 token 从 `pendingReview` 过滤掉，前端没有原始数据可恢复；改为服务端全量返回、前端隐藏
- `replace-bim` 报 `config is not iterable`：targets 已改成对象格式，代码仍按数组遍历
- `targets-replaced.json` 在对象格式下会报 `map is not a function`：已兼容数组/对象
- `szewtwinjs-core` 突然消失：回收站记录显示 **2026-11-02 17:26** 删除到回收站（2.94 GB），已恢复
- GitHub Desktop 把 `szewtwinjs-core` 显示为空：它是嵌套 Git 仓库；后移除其 `.git` 并为外层仓库提交文件
- GitHub Desktop 提交失败：日志显示 `execvpe(/bin/bash) failed`，pre-commit 的 `#!/usr/bin/env bash` 被解析到 WSL bash，而 WSL 只有 `docker-desktop`、没有 `/bin/bash`；改为 `#!/bin/sh` 后恢复
- `replace-bim` 未替换 `lib/cjs` 里的 `.bim`：`scan-exclude.json` 排除 `lib` / `cjs` 等构建产物，需要重新构建
- `replace-staged` 测试失败：
  - 根目录 `.mocharc.jsonc` 仍指向 `@itwin/build-tools/mocha-reporter`（不在 targets 范围内）
  - `StringUtils.test.ts` 期望 `iVaultJs`，字节数组解码是 `iModelJs`
  - `UnitDefinitionResolver.test.ts` 期望 492，实际 500
  - `@szewec/units-schema` 未导出 `./package.json`
  - `ParseUtils.test.ts` 出现脏映射 `szewDM`，代码期望 `szewec`
  - `XmlParser.test.ts` 的 `CorDmA` 别名无法解析
- README 一键启动和分步流程混在一起：增加「两种使用方式」总览，快速方式和完整流程各自独立成章
- `replace-bim` 的运行顺序一度写成在 `replace-staged` 之后，实际应在发包前运行，已统一修正
